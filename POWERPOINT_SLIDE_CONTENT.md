## General Design Guidelines

### **Color Scheme:**
- **Primary:** SAP brand colors (if available) or professional blue
- **Accent:** Use one accent color for highlights
- **Text:** Dark gray/black on light background
- **Background:** White or very light gray

### **Typography:**
- **Title:** 36-44pt, Bold
- **Subtitle:** 24-28pt, Regular
- **Body Text:** 18-20pt, Regular
- **Bullet Points:** 16-18pt, Regular
- **Font:** Sans-serif (Arial, Calibri, or SAP corporate font)

### **Spacing:**
- **Margins:** Minimum 0.5 inch on all sides
- **Line Spacing:** 1.15-1.5
- **Between Sections:** 0.3-0.5 inch
- **White Space:** Don't fill every inch - use white space effectively

### **Visual Consistency:**
- Use same icon style throughout
- Consistent color scheme
- Same bullet point style
- Consistent card/box design for agents

### **Accessibility:**
- High contrast (text vs background)
- Large, readable fonts
- Clear hierarchy
- Alt text for images (if using)

### **What NOT to Include:**
- ❌ Technical details (Flask, SocketIO, OAuth)
- ❌ Backend architecture diagrams
- ❌ Code snippets
- ❌ Database schemas
- ❌ API endpoints
- ❌ Streamlit mentions
- ❌ Migration stories

### **What TO Emphasize:**
- ✅ User benefits
- ✅ What users can do
- ✅ Simple, clear language
- ✅ Visual elements (icons, simple diagrams)
- ✅ Key messages

## Slide Transition Notes

### **Between Slides:**
- Use simple transitions (fade or none)
- Don't use distracting animations
- Keep it professional

### **During Presentation:**
- **Slide 1:** Start with title, introduce yourself
- **Slide 2:** Explain features briefly
- **Slide 3:** Focus on Wiki MD Agent (recommended)
- **Slide 4:** Quick overview, then move to demo

### **Timing:**
- **Slide 1:** ~2 minutes
- **Slide 2:** ~3 minutes
- **Slide 3:** ~4 minutes
- **Slide 4:** ~1 minute
- **Total:** ~10 minutes before demo
